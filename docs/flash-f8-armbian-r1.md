# F8 Armbian R1 测试包：刷入与首次设置

本包面向本项目已核对分区布局的 F8 RK3588S 平板。沿用已实机启动的 C4 BOOT，ROOTFS 新增图形账户向导及当前已验证硬件配置。**这个新组合尚待首次刷入冷启动验收**，不能将旧系统硬件验收当作本包启动验收。

## 文件与刷入

解压 ZIP 后，在 RKDevTool 的“下载镜像”页面使用以下两项。文件校验值见 SHA256SUMS、image-manifest.json；不要在“升级固件”入口加载单独分区文件。

| 分区 | 起始地址（512字节扇区） | 文件 |
| --- | --- | --- |
| boot | 0x00008000 | BOOT_F8_ARMBIAN_R1.img |
| rootfs | 0x00078000 | ROOTFS_F8_ARMBIAN_R1.ext4.img |

ROOTFS 逻辑大小12GiB，写入会替换原系统账户、设置和文件。需要保留的数据应先另存。包内不含用户私人回退镜像、Wi-Fi密码、浏览器资料、测试SSH授权密钥或共享SSH主机私钥。

1. 平板关机并进入 Loader，等待工具显示发现 LOADER 设备。
2. 读取分区表，核对上述地址与设备实际布局相同，只勾 boot 和 rootfs。其他分区、Loader、Parameter/GPT、U-Boot、Recovery、OEM、userdata不勾选；不擦除Flash或改分区表。
3. 选择两个已解压原始镜像，执行写入并等待工具报告完成。两项均成功后重启。

BOOT 与 C4 字节相同，SHA256 `fbbfa1ece55b3c62decbd10ae9c2ac98ed5d717dd5f8b941c49004deb6c0903a`；内核为官方6.1.115-vendor-rk35xx，不能替换成历史C3错误内核。本包ROOTFS UUID与匹配BOOT一致。当前根文件系统12GiB，不自动改动原分区边界；扩大文件系统另行处理。

## 首次开机

首次进入临时的本地设置会话，自动打开“F8 首次开机向导”：选择语言/时区 → 创建用户名与密码 → 可选连接Wi-Fi → 阅读平板使用说明 → 完成设置。支持离线完成，用户名以小写字母开头；密码至少8个字符。

默认使用密码登录，可在向导显式选择自动登录。完成后点击“进入登录界面”，选择自己创建的账户登录。若选择了自动登录，也可正常重启进入新桌面。临时设置账户会禁用交互登录，不会反复重建旧测试账户。向导中途退出可从设置会话重新登录/重启后继续；不要在应用设置时断电。

创建的账户具有常规sudo权限，执行管理命令需要自己的密码。镜像不保留旧 `f8test` 测试账户与免密码通用sudo，也不继承开发者远程访问权限。SSH默认不启动；确有需要时，在本机终端执行 `sudo systemctl enable --now ssh.service`，使用自己的用户名与密码连接，首次核对本机 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 指纹。主机密钥首次启动独立生成。

## 平板使用

- 输入：轻触文本框使用 Plasma 虚拟键盘；按键短振30ms，可在虚拟键盘设置关闭。
- 连接：系统设置连接Wi-Fi、扫描/配对蓝牙；USB-C支持已测试的USB2 U盘，文件管理器安全移除后拔出。
- 相机：F8相机开始预览；Kamoso或网页使用前勾选“兼容中继”，保持F8相机运行。网页使用“Chromium（相机兼容）”，正常授权。F8自身AVI录像无声；Kamoso/兼容浏览器已在旧系统验收带声音录像。
- 传感器：“传感器观察”有姿态正方体、水平仪与读数；静置校零只影响当前观察。指南针不带原用户校准，需要个人重新校准并平放，远离磁性保护套/音箱。
- 保护盖：合盖熄屏、开盖亮屏；“F8 霍尔与振动测试”可以关闭联动。此功能只控制显示。
- 随时从应用菜单打开“F8 使用指南”重读说明。

## 当前边界与验收

相机仍为基础640×480/14fps，分辨率、色彩管理、对焦、RAW等后续完善；普通Chromium直接调用物理相机仍有兼容问题。电池电量/充电采样、高压PD、休眠和CPU调频尚未完整适配，沿用已验证供电方式，不以当前电量百分比推断续航。

新包首先验证向导、创建用户、SDDM登录和屏幕键盘；然后验证重启后新账户/配置保留，以及Wi-Fi、GPU、触摸/旋转、声音/麦克风、USB、蓝牙、相机、霍尔和按键短振。镜像文件系统检查与离线ARM64账户测试通过，不替代以上真机冷启动测试。正常启动不再自动导出旧USB日志盘。
