# 相机后续适配与设置清单（2026-11-02）

用户明确：当前相机只是工作起来，后续仍要增加分辨率、色彩管理、对焦、RAW等设置。**目前只完成基础可用阶段，不能标记相机完整适配完成。** 本轮仅记录范围与验收要求，没有修改平板配置或启动新的硬件测试。

## 当前可用基线

前后摄真实预览、方向、专用APP拍照与录像；虚拟摄像头中继；Kamoso预览／拍照／带声音录像；兼容Chromium本地页预览／带声音录像，以及CoderTools网站实时取景已验收。日常使用仍需F8相机持续预览并开启中继，浏览器使用兼容入口。

当前应用／中继固定640×480、14fps。F8专用AVI仍无声。后摄OV8858输入3264×2448、前摄GC5035输入2592×1944的链路曾实际使用，**不等于这些分辨率的成品照片、录像或所有帧率已经验收**。前摄采用开发画质配置，部分新版降噪／锐化模块禁用；两摄轻微偏淡待优化。

## 待办与验收

| 项目 | 要补的能力 | 验收要求／边界 |
| --- | --- | --- |
| 能力与分辨率 | 分别列出前后摄真实模式；预览、拍照、录像的分辨率和帧率选择；中继能力同步 | 按真实sensor/ISP模式生成选项；验证尺寸、stride、宽高比、裁剪、持续帧率、内存与切换恢复，不只修改界面下拉框或上采样冒充全分辨率 |
| 基础手动控制 | 曝光时间、增益/ISO映射、曝光补偿、自动/手动白平衡、AE/AWB锁定及恢复自动 | 核对每颗sensor实际控制范围、增益标度和AIQ行为；读回与画面响应一致，不能被下一帧算法覆盖；设置按镜头保存 |
| 色彩管理与画质 | 排查偏淡；核对YUV范围/矩阵、gamma、WB、CCM、LSC及降噪/锐化；提供适当的色彩控制 | 在可重复光照／参照物下验证；区分真实校准与用户饱和度/对比度偏好；预览、照片、录像、中继色彩一致，输出色彩标记正确；显示配置与相机校准分别处理 |
| 对焦 | 优先核实后摄VCM、供电、I2C通信与镜头行程，再加入手动/自动/单次对焦及锁定 | 当前DW9714仍disabled、历史通信未通过，不直接启用未知控制；需近远目标、行程边界与重复动作实测。前摄先核实是否有可调焦硬件，不套用后摄能力 |
| RAW | 增加真实RAW采集、保存、模式选择与参数元数据；评估DNG输出 | 旧的底层RAW少量取帧记录不等于APP完整支持。核对位深、Bayer排列、打包方式、stride、黑白电平、曝光/增益、WB、方向；用独立工具解码检查，不能把裸文件改后缀当DNG |
| 录制与音频 | F8专用APP录音、编码/码率/容器选择及音画同步；高分辨率编码能力 | 区分Kamoso/浏览器已能录音与F8专用AVI未录音；验证实际编码路径、文件完整性、同步、长录与磁盘不足收尾，不只看文件生成 |
| 设置与状态 | 分镜头保存设置、恢复默认、真实能力提示、必要的锁定/忙碌状态 | 不支持的选项不伪装可用；切镜头、停止、关窗、客户端退出后正确恢复；不意外开启相机或丢失正在录制的数据 |
| 稳定性与集成 | 冷启动首次出流、反复切换、休眠恢复、多个客户端、异常退出与打包集成 | 中继自动建节点的重启持久化仍待实测；核对CPU/内存/温度、丢帧、音画同步和进程回收；普通浏览器直接枚举物理节点的问题仍未在内核层修复 |

建议后续顺序：真实能力清单与分辨率/帧率 → 基础控制及色彩 → 后摄对焦 → RAW/DNG与录制完善 → 冷启动、稳定性和最终打包。RAW底层核对可作为色彩分析的辅助，安排时按实际依赖调整。

## 继续工作时保留的约束

- 保留目前通过验收的配置和可回退版本，各项独立验证，不把中继兼容等同于物理ISP已对全部软件兼容。
- 不以其它模组完整IQ重命名作为最终调校，不伪造分辨率、RAW或对焦能力。
- 继续禁止CIF/DPHY/ISP热重绑；BOOT构建使用已归档的固定官方Image路线，不能复用失败C3内核。
- 充电/BQ/PD与CPU策略仍按原待办暂缓，不因相机设置扩展顺带改动。
